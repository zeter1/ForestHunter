# Forest Hunter — Ultimate Hunt

Forest Hunter is a browser-based 3D FPS built with Three.js/WebGL. Hunt boars, collect weapons and supplies, complete contracts, improve your character and fight the Alpha Boar boss.

## Get started

Download https://github.com/zeter1/ForestHunter/archive/refs/heads/main.zip and extract the whole folder. Open `index.html` in a desktop browser. For predictable development behavior, run this command from the project folder:

```sh
python -m http.server 8000
```

Open http://localhost:8000. The game needs JavaScript, WebGL, a keyboard and mouse, and internet access for the initial Three.js download. Python is only needed for the optional server. Reduce graphics quality on slower computers.

## Controls

| Action | Input |
|---|---|
| Move | `WASD` / arrow keys |
| Run / jump | `Shift` / `Space` |
| Fire / aim | Left / right mouse button |
| Select weapon | `1–9` / mouse wheel |
| Reload | `R` / Russian-layout `К` |
| Pause | `Esc` |

## Features and development

The game includes three difficulty levels, character progression, contracts, weapons, supplies and graphics settings. See the [architecture](docs/ARCHITECTURE.md), [verification notes](README.md#проверка-и-ci) and [change history](CHANGELOG.md). These detailed documents are currently in Russian.

Automated checks do not cover every interactive gameplay scenario. A fully offline setup requires a local copy of Three.js.
