# AGENTS.md — ForestHunter

Сначала прочитайте [README.md](README.md) и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Команды запуска и проверок находятся в README; CI владеет автоматической проверкой, архитектура — границами модулей.

Сохраняйте разделение чистых simulation contracts и Three.js runtime; владельцы описаны в архитектуре. Не меняйте баланс игры при чистой правке документации или рефакторинге. Headless boot не доказывает полный gameplay, Web Audio и производительность GPU.

Читайте только владельцев текущей задачи и ближайшие проверки. Сохраняйте историю CHANGELOG и фиксируйте принятую правку одним блоком с фактическим локальным временем и UTC offset. Не заявляйте проверенный браузерный сценарий без его выполнения.
